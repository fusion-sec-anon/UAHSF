# 🧠 Prompts

This folder contains the prompt assets accompanying our paper.

The prompts are organized in three parts:

- **UAHSF prompts** (`uahsf/`): the uncertainty-aware prompt template, I/O schemas, parsing rules, inference parameters, and packaged example cases.
- **Baseline prompts** (`baseline/`): ChatGPT-FS prompts in zero-shot / one-shot / few-shot settings.
- **Prompt ablations** (`ablations/`): prompt-only variants that remove specific uncertainty indicators.
